# Pacote de desenvolvimento USB

Baixe `SmartPDV-USB-development.zip` pelo botão **Download raw file** do GitHub.

Contém as fontes integradas e o Agent Win7 compilado. **Não é um instalador pronto para os caixas:** não inclui driver USB Windows 7 assinado. O reconhecimento físico do LS2208 e a autorização no VR continuam pendentes.

Consulte `docs/usb-reader-redirection.md` e `docs/usb-validation-report.md` no projeto.
